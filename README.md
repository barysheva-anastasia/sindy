Данные чеклиста лояльности (пять траекторий) прогоняются через SINDy-тулкит
Delahunt–Kutz, лучшая итерация культинга выбирается автоматически и
проверяется на прогнозе вперёд.

Особенности:

- Имена признаков анонимизированы: x0..x103 вместо исходных названий.
- Данные — только локальный parquet (data_loyalty_v4/).

## Данные
В parquet файле усредненный чеклист лояльности -- набор из 104 бинарных фичей (наличие продуктов, транзакционная и продуктовая активность), снимаемых ежедневно. Чеклист усредняется для 10 групп клиентов из двух сегментов (old и new), по 5 групп на каждый сегмент. Сегменты состоят из клиентов не младше 30 дней в экосистеме на момент начала сбора данных (2024-01-01), однородных по соц-дем параметрам (отличаются между сегментами) и достаточно активных на весь период сбора данных (2024-01-01 -- 2026-01-01).

## Установка
pip install -r requirements.txt
Запускать всё из этой директории (thesis_copy/) — модули импортируются
как from core..., from load_loyalty_v4_data import ... и т.п., без
установки пакета.

## Как воспроизвести

1. **(Опционально) пересчитать тулкит:**
python test_sindy_toolkit_loyalty_v4.py
Перезапишет runResults_loyaltyV4_run1_*.pickle и outputFile_loyaltyV4_run1_*
(старые файлы этого прогона удаляются перед запуском). Каждая из пяти
траекторий ограничена maxRunTimeSecs=5600, так что полный прогон занимает
часы.
2. **Открыть `thesis_demo.ipynb`** — он читает готовый пикл
(PICKLE_FILE = 'runResults_loyaltyV4_run1_initialRun_2968.pickle',
переменная TRAJ выбирает одну из пяти траекторий) и строит все графики
тезиса.
3. **`check_traj.py`** и **`iterationScore.py`** можно использовать отдельно
для диагностики новых пикл-файлов или собственных траекторий.

## Важные детали

- sindy_toolkit_func вызывается с boundednessMethod='trapping' и без
ограничения на boundednessMaxNumFreeEntries — на полной 86-признаковой
библиотеке (7482 активных элемента на траекторию) trapping-репарация
работает на всех итерациях, а не только после отсева до маленькой
библиотеки.

- в прогоне участвует только один сегмент из двух в parquet (OLD_SEGMENT)
